# GestorMinecraft (Archivado y Descontinuado)

⚠️ **Este proyecto ha sido archivado y trasladado a [GetMineHub](https://github.com/PaxNotFun/GetMineHub/).**

### Motivo del cambio
Después de una evaluación técnica, decidí migrar el proyecto a otro lenguaje de programación. Python presentaba varias limitaciones importantes para el crecimiento de la aplicación (rendimiento, distribución y falsos positivos frecuentes en antivirus), por lo que estoy reescribiendo completamente la aplicación en **Go**.

### ¿Qué puedes hacer ahora?
- El nuevo proyecto activo es **[GetMineHub](https://github.com/PaxNotFun/GetMineHub/)**.  
  [Ir a GetMineHub →](https://github.com/PaxNotFun/GetMineHub/)

- **Si deseas seguir usando temporalmente la versión actual en Python**:
  1. Ve a la carpeta de la aplicación en tu sistema:  
     `%appdata%\getminehub` (o simplemente `roaming/getminehub`)
  2. Abre el archivo `settings.json`
  3. Cambia el valor de `"check_for_updates"` a `false`

  De esta forma la aplicación dejará de mostrar el aviso de actualización.
